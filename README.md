
# ShirFridmanMor - Final Full Stack Project

## Project Description
A full-stack AI chatbot application that allows users to have conversations with an AI assistant.

## Technologies
- Frontend: React, Vite
- Backend: Python
- Database: MySQL
- AI: OpenAI API

## Project Structure
- Backend - Python server and API
- Frontend - React application
- Database - SQL database files

## Setup
1. Install Python dependencies using requirements.txt.
2. Install frontend dependencies using npm install.
3. Import the SQL database into MySQL.
4. Configure the environment variables.
5. Start the backend and frontend applications.
